# BharatType Hindi Text Utilities

Open-source Hindi text utilities for JavaScript and TypeScript applications.

BharatType Hindi Text Utilities provides reusable tools for working with Hindi text, including Kruti Dev 010 to Unicode conversion and Unicode text normalization.

## Features

- Kruti Dev 010 to Unicode conversion
- Hindi text processing
- Unicode text normalization
- Zero-width character removal
- Devanagari text detection
- TypeScript support
- JavaScript compatible
- Browser and Node.js friendly
- No UI dependencies
- MIT licensed

## Installation

npm install @bharattype/hindi-transliteration
