# BharatType Hindi Transliteration

Lightweight Hindi transliteration utilities for JavaScript and TypeScript applications.

## About

BharatType Hindi Transliteration is an open-source project focused on making Hindi text processing and transliteration easier for web developers.

The project provides a small, reusable API that can be integrated into JavaScript and TypeScript applications.

## Features

- TypeScript support
- Lightweight API
- Simple converter interface
- Works in JavaScript and TypeScript projects
- No UI dependencies
- Suitable for browser and Node.js applications

## Installation

```bash
npm install @bharattype/hindi-transliteration
